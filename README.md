# MarineFlags

An app for reading, composing and learning signal flag messages in the International Code of Signals. It runs in the browser, works on a phone, and keeps working without a connection once installed.

Try it at <https://kjwesthoff.github.io/MarineFlags/>. To install it, open that page on your phone and choose "Add to Home Screen" from the browser menu.

## Using the app

The app has three tabs at the bottom: Compose, Reference and Learn.

### Compose: build and read a message

1. Tap flags on the flag keyboard. Each flag hangs on the hoist, and the meaning appears underneath as you go. For example, N then C reads "I am in distress and require immediate assistance."
2. You can also type a group such as `NC` or `AE1` in the box above the keyboard.
3. A message can have several hoists, side by side and read left to right. Tap "Add hoist" for another, and tap a hoist to select it.

Things you can do with a message:

- **Rearrange:** drag a flag up or down a hoist, or to another hoist. Drag it onto the keyboard to remove it, or tap it for Move up, Move down and Remove buttons.
- **Add what a signal asks for:** when a signal can take more information, buttons appear under its meaning, such as "Add time", "Add position", "Add number" or a table to pick from. A single T offers "Add time"; a signal about a casualty offers the body-region table.
- **Remove:** "Remove" above the selected hoist deletes that hoist; "Clear message" starts over.
- **Make room:** "Hide flag keyboard" collapses the keyboard, and "Show flag keyboard" brings it back. The keyboard can be laid out as QWERTY or A–Z.

Repeated flags are handled for you: typing `MAA` hoists M, A and the second substitute, as a ship with one set of flags would.

### Reference: look things up

- **Flags:** all 40 flags with their code word, pronunciation and meaning. "Add as a new hoist" puts a flag in your message.
- **Code book:** about 1,800 signals, browsable by section or searchable by code or by words ("tow", "doctor"). Tap a signal to see it as flags in Compose.
- **Guide:** how flag signaling works, terms, procedure signals, Morse code, distress signals, call sign prefixes by country, and "Add a position", which takes your current location or a point on a map.

### Learn: practise

Tap "Start learning" for a short session of about ten questions. New flags are shown before you are asked about them, and anything you miss comes back sooner while what you know comes back later. You can also practise one thing at a time: naming flags, finding flags, single-flag signals, the phonetic alphabet, common signals, or reading hoists. Progress is saved on your device.

## For developers

The app is a static, offline-first PWA built with React, TypeScript and Vite. There is no backend.

```sh
npm install
npm run dev      # start the dev server
npm test         # unit tests
npm run build    # type-check and build
```

Pushing to `main` runs the tests and deploys to GitHub Pages (`.github/workflows/deploy.yml`).

Code layout:

- `src/data/flags.ts` – the 40 flags as generated SVG, with names, pronunciation and single-flag meanings.
- `src/data/codebook.json` – 1,819 signals from the general and medical sections of Pub. 102, generated by `tools/build_codebook.py`.
- `src/data/tables.json` – the tables and lists that signals refer to and the guide topics, generated by `tools/build_tables.py`.
- `src/data/notes.json` – meanings from outside the code book, such as naval use.
- `src/lib/signals.ts` – resolving substitutes, decoding hoists, encoding text to flags, code book search.
- `src/lib/values.ts` – the further information a signal can take (time, position, number and so on).
- `src/lib/learn.ts` – practice decks, scheduling and question building.
- `src/screens/` – the Compose, Reference and Learn screens.

Rebuilding the data from the source PDF (not included in the repository):

```sh
pdftotext -layout "Signalbog - International Code of Signals (1969 - Revised 2020).pdf" pub102.txt
python3 tools/build_codebook.py pub102.txt src/data/codebook.json
python3 tools/build_tables.py pub102.txt src/data/tables.json
```

## Sources

Signal meanings come from the *International Code of Signals* (Pub. 102, 1969 edition, revised 2020), published by the US National Geospatial-Intelligence Agency.

Call sign prefixes (`tools/itu_prefixes.json`) are the ITU allocations of international call sign series (Radio Regulations, Appendix 42), taken from the list on Wikipedia's “ITU prefix” page.

Naval meanings (`src/data/notes.json`) are not from the code book. The US Navy single-flag meanings follow the Navy's Basic Military Requirements training manual (table 4-3, commonly used signals, as published at navyadvancement.tpub.com) and the flag table at navysite.de; BZ follows the US Naval History and Heritage Command's account of “Bravo Zulu”.

The position map uses OpenStreetMap tiles when online, over a bundled Natural Earth coastline that works offline.
