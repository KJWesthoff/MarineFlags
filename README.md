# MarineFlags

An offline-first PWA for reading, composing and learning International Code of Signals flag messages.

## Status

Phases 1 (foundation) and 2 (compose and reference) are done.

- **Compose** – build a message from flags or by typing a group; each hoist is decoded live.
- **Reference** – all 40 flags with names and meanings, and the searchable code book. Tapping a signal shows it as flags.
- Installable and usable offline (service worker and web manifest via `vite-plugin-pwa`).

Code layout:

- `src/data/flags.ts` – the 40 flags as generated SVG, with names, pronunciation and single-flag meanings.
- `src/data/codebook.json` – 1,809 signals from the general and medical sections of Pub. 102, generated by `tools/build_codebook.py`.
- `src/lib/signals.ts` – resolving substitutes, decoding hoists, encoding text to flags, code book search.
- `src/screens/` – the Compose and Reference screens.

Next: training, then camera recognition.

## Commands

```sh
npm run dev      # start the dev server
npm test         # unit tests
npm run build    # type-check and build
```

Rebuilding the code book from the source PDF:

```sh
pdftotext -layout "Signalbog - International Code of Signals (1969 - Revised 2020).pdf" pub102.txt
python3 tools/build_codebook.py pub102.txt src/data/codebook.json
```

## Source

Signal meanings come from the *International Code of Signals* (Pub. 102, 1969 edition, revised 2020), published by the US National Geospatial-Intelligence Agency.
